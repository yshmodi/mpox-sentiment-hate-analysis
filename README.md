# Sentiment and Hate Analysis of Mpox Instagram Dataset

🚀 **Analyze public sentiment and detect hate speech from Mpox-related Instagram posts using machine learning and NLP techniques.**

## 📜 Project Description
This project examines how social media discourse evolved during the Mpox outbreak by analyzing Instagram comments. Using a combination of sentiment analysis and hate speech detection, this project applies machine learning techniques to provide actionable insights into online behavior during public health crises.

## 🛠️ Key Features
- **Sentiment Analysis:** Classify Instagram comments into positive, negative, and neutral sentiments.
- **Hate Speech Detection:** Identify harmful content using hate speech classifiers.
- **Machine Learning Models:** Implement Decision Trees, Logistic Regression, and Random Forest for text classification.
- **Data Preprocessing:** NLP techniques for cleaning, tokenizing, and vectorizing text data.
- **Visualization:** Insights presented with graphs and charts.

## 📂 Repository Contents
- `sentiment_hate_analysis.ipynb`: Jupyter Notebook containing the code for data preprocessing, model training, and analysis.
- `report.pdf`: Comprehensive report detailing the methodology, results, and findings.

## 📊 Results
Key findings include:
- Logistic Regression achieved an accuracy of **75%** for sentiment and hate speech classification.
- Random Forest demonstrated an accuracy of **74%** for the same.
- Whereas, Decision Tree classifier demonstrated an accuracy of **68%** 
- Detailed metrics and insights are available in the [PDF Report](report.pdf).
